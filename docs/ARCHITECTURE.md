# Business Empire: Ultimate — архітектура веб/Android-версії

Гра — набір класичних JS-модулів (без збирача), що спільно працюють зі станом `state`.
Android-застосунок (`android/`) — WebView, який завантажує `business-manager/index.html` з assets.

## Модулі (порядок завантаження)

| Файл | Відповідальність |
|---|---|
| `core.js` | Довідники (міста, райони, товари, підприємства, галузі, компанії), утиліти, бухгалтерські категорії, збереження |
| `sim.js` | Ядро симуляції: роздріб (щогодини), виробництво, склад, ринок B2B, IT, авто, нерухомість, персонал, макроекономіка, ІІ-компанії, біржа, бухгалтерія, події, досягнення |
| `econ2.js` | Світова економіка: сировина (нафта, газ, метали, зерно) з дефіцитами, валюти міст, мита й торгові війни, рівні складності |
| `ai2.js` | Розширений ІІ конкурентів: стратегії, ціни, технології, кредити, заводи, рейдерство, реакція на гравця |
| `gov.js` | Державне управління: міністерства, бюджет, субсидії, податкові перевірки, антимонопольна служба, суди |
| `hq.js` | Штаб-квартира: директори виконують доручення |
| `bank.js` | Власний банк гравця |
| `fun.js` | Стартапи (венчур) і спортивне спонсорство |
| `city3d.js` | 3D-місто на Three.js (склеєна геометрія, інстанси, обробка втрати контексту) |
| `ui.js` | Інтерфейс: екрани, дії, обробники |

## Ритм симуляції

- `tick()` — 1 ігрова година: роздрібні продажі, дії керуючих.
- `endOfDay()` — о 00:00 пакетно: зарплати, оренда, виробництво, контракти, нерухомість, банк, `worldDaily` (сировина, валюти),
  `econDaily` (цикл, ставка, ціни), `aiDaily` (ІІ-компанії, біржа), бухгалтерія, податки; далі `HOOKS.day` (уряд, антимонопольна служба,
  штаб, банк, стартапи, спорт).
- Дорогі розрахунки (ринкові частки, справи АМКУ) виконуються раз на добу, а не щокадру.

## Збереження

`localStorage` (`bizimperia_save_v2`) + експорт/імпорт текстовим кодом. Нові поля додаються через `migrateState()`,
тож старі збереження продовжуються (складність «Магнат», світова економіка й уряд створюються при першому завантаженні).

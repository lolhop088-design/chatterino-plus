# chatterino-plus
Chatterino + - Android client for Twitch with 7TV, BTTV, FFZ emotes

## 🏙️ Бізнес Імперія (Android-гра)

Хардкорний економічний симулятор: від звичайної людини з $4 000 до глобальної корпорації.

**Що є в грі**
- **Персонаж:** ім'я, зовнішність, місто (Київ, Львів, Одеса, Берлін, Нью-Йорк), житло, особисті витрати, найманий труд, курси, кредитний рейтинг.
- **Макроекономіка:** цикли зростання / буму / рецесії / кризи, інфляція, облікова ставка ЦБ, безробіття, курс валюти, ціни на нерухомість, податкові реформи.
- **Роздріб:** 8 типів (кав'ярня, бургерна, мінімаркет, квіти, ресторан, одяг, електроніка, автосалон), ціни, закупівлі, псування, персонал, маркетинг, покращення.
- **Виробництво:** ферми, шахти, кар'єри, нафта, харчовий комбінат, швейна фабрика, металургія, хімзавод, мікросхеми, електроніка, автозавод, електростанція, логістичні центри; спільний склад, B2B-ринок із попитом і пропозицією, логістика із затримками, знос і аварії, страйки.
- **Ланцюжки:** руда → сталь → автозавод → автосалон; нафта → пластик → мікросхеми → електроніка → магазин; ферма → комбінат → мінімаркет.
- **Авто:** конструктор (сегмент, двигун, кузов, комплектація) з якістю, собівартістю й ринковою ціною.
- **IT:** застосунки, ігри, вебсервіси, хмара, ігрові рушії, ОС; R&D-дослідження.
- **Нерухомість:** квартири, будинки, офіси, іпотека, оренда; будівництво ТЦ, ЖК і бізнес-центрів.
- **Фінанси:** звіт про прибутки та збитки, баланс, амортизація, щотижневі податки, кредити, депозитні відсотки.
- **Біржа:** ~50 ІІ-компаній (пародійні назви) відкривають і закривають точки, банкрутують, поглинають одна одну, платять дивіденди; власне IPO.
- **Корпорація:** відділи кадрів, бухгалтерії, юридичний, R&D, маркетинг і продажі; ролі, навички та мораль персоналу.
- **3D-місто** на Three.js з 9 кварталами та 96 ділянками, днем і ніччю; режими якості для телефонів і автоматичний перехід на 2D.

**Структура**
- `business-manager/` — гра (`core.js` дані, `sim.js` симуляція, `ui.js` інтерфейс, `city3d.js` 3D-місто).
- `android/` — Android-застосунок (WebView), що пакує гру в APK.
- `.github/workflows/android-apk.yml` — збирає APK і публікує його в **Releases**.

Назви компаній-конкурентів вигадані та пародійні; гра не пов'язана з реальними брендами.
